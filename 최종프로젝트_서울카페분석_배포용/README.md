# ☕ 서울시 카페 매물 추천 시스템

본 프로젝트는 서울시 상권 내 카페 입지의 성공 가능성을 시각화하고,  
추천 매물을 제공하는 Streamlit 기반 웹 애플리케이션입니다.

---

## 🛠 실행 방법

### 1. 패키지 설치

아래 명령어를 통해 실행에 필요한 라이브러리를 설치합니다:

```bash
pip install -r requirements.txt
```

### 2. 앱 실행

```bash
streamlit run 통합시스템.py
```

## 📌 주요 기능

### 1. 서울 상권 카페 현황
- 상권별 카페 수, 성공률, 밀집도 등을 지도에 시각화
- 상권 클릭 시 해당 구역의 카페 리스트, 통계 정보 제공

### 2. 서울 카페 매물 추천
- 보증금/월세/면적/성공률 조건을 필터링
- 상권 클릭 시 조건에 맞는 추천 매물 지도와 표로 제공
